# christmas-list
Family Christmas list tool for adding items you desire, ignoring anything Allie requests, and tracking Santa's haul (assuming everyone's been nice, not naughty)

## What it does

- Everyone keeps a wish list.
- Everyone else can claim items, add off-list surprises and stocking stuffers, and log gift ideas, all hidden from the person receiving them.
- Built for one family's traditions, Santa included.

## Run it locally

Needs Node.js 22 or newer.

```
npm install
npm run dev      # local site with live reload
npm run build    # the same check-and-build GitHub runs before deploying
```

Pushing to `main` deploys to https://bgs3jc.github.io/christmas-list/.
